# Text snippets

I testi generati automaticamente si trovano in:

```txt
outputs/text_snippets/
outputs/generated_report_sections/
```

Contengono:

- introduzione
- metodo
- risultati euristiche
- risultati user test
- risultati UEQ
- risultati NPS
- conclusioni

Sono bozze pronte da adattare nel report. I testi data-driven dipendono dai CSV e dalle tabelle generate dalla pipeline.
