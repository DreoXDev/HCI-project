# Presentation Manual

## Recommended Structure

1. Cover.
2. Index.
3. Introduction.
4. Problem description.
5. Evaluation environment.
6. Compared apps/systems.
7. Heuristic evaluation.
8. User testing.
9. Questionnaire.
10. Final synthesis.
11. Optional appendix.

## Heuristic Evaluation

Include objective, heuristic set, evaluator profile, problems found, severity/priority, system comparison and recommendations.

Required data: expert profiles, consolidated problems, severity ratings.

Generated automatically: evaluator tables, problem matrices, severity charts, common criticalities.

Manual review: wording of problem descriptions and final recommendations.

## User Testing

Include objectives, user profile, tasks, effectiveness, efficiency, errors and statistical comparison.

Required data: user ids, app, task id, outcome, time, errors, help requests and notes.

Generated automatically: outcome matrix, time charts, OET comparison, statistical tables.

Manual review: task wording and interpretation of edge cases.

## Questionnaire

Include UEQ method, NPS, key item analysis, benchmark, subgroups and distributions.

Required data: completed UEQ/NPS answers per user and app.

Generated automatically: transformed UEQ scores, item tables, benchmark charts, heatmaps and NPS.

Manual review: narrative synthesis. Do not reintroduce raw 1..7 means as official UEQ results.

## Appendices

Appendices can include individual heuristic evaluations, support materials, user tasks and detailed tables. Keep them configurable via `config/appendices.yaml`.
