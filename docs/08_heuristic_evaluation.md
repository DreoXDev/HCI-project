# Heuristic Evaluation

## Collection

Collect one row per problem or per evaluator/problem rating, depending on the stage. Each problem needs an app, id, description, violated heuristic, severity and optional redesign suggestion.

## Severity

Use consistent severity anchors. The pipeline aggregates ratings across experts and produces priority bands, problem matrices and summaries.

## Evaluator Profiles

Record usability experience and domain experience separately. This allows the report to distinguish method expertise from domain familiarity.

## Generated Slides

The toolchain generates evaluator tables, matrices, top problems, shared criticalities, severity distributions and recommendation-oriented summaries.
