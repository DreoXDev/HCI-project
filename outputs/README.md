# Outputs

This folder contains generated artifacts. Most files can be regenerated by the pipeline.

Common subfolders:

- `charts/`: generated PNG charts.
- `tables/`: generated CSV tables.
- `reports/`: validation reports, quality checks, doctor report and run manifest.
- `slides/`: generated `final_report.pptx` and PDF exports.
- `slide_assets/`: intermediate assets used by slide generation.
- `archive/`: optional place for old generated outputs kept for reference.

Do not manually edit generated charts/tables as source of truth. Change input data or configuration and rerun the pipeline.
