# HCI Toolkit - Deliveroo vs Glovo

Toolkit Python per importare dati Formbricks e CSV osservazionali, validarli e generare analisi, grafici, tabelle, testi e slide per il confronto HCI Deliveroo vs Glovo.

## Quick Start

```powershell
python -m pip install -r requirements.txt
python -m src.cli validate
python -m src.cli full-pipeline --plot-style both
```

I dati demo inclusi sono inventati e servono solo per provare la pipeline.
